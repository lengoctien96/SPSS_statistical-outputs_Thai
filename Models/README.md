# SPSS Statistical Outputs (Thai Graduation Thesis)

This repository contains statistical outputs and models used in the graduation thesis project.  
The focus is on **Structural Equation Modeling (SEM)**, showcasing latent constructs, observed indicators, and model fit indices.

---

## 📊 Structural Equation Model (SEM)

The diagram below illustrates the SEM with four latent variables (**TE, KA, KT, JP**) and their observed indicators.  
It also includes standardized path coefficients and model fit indices.

![SEM Diagram](attachments/qAEschm9MUcGDMwZu9czz.png)

---

## 🔎 Model Fit Indices

- **Chi-square** = 381.537; df = 269  
- **Chi-square/df** = 1.418  
- **GFI** = 0.889  
- **CFI** = 0.962  
- **TLI** = 0.957  
- **RMSEA** = 0.042  
- **PCLOSE** = 0.924  

These values indicate a **good model fit**, with CFI and TLI above 0.95 and RMSEA below 0.05.
